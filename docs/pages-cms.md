# Pages CMS 使用指南

后台入口：<https://app.pagescms.org>。

博客地址：<https://morpheusdn.github.io>。

仓库：<https://github.com/MorpheusDN/morpheusdn.github.io>，日常编辑选择 `main` 分支。

## 首次连接

1. 确认仓库的 `main` 分支已经包含根目录的 `.pages.yml`。
2. 打开后台，使用拥有该仓库写权限的 GitHub 账号登录。
3. 按提示安装 Pages CMS GitHub App，选择 **Only select repositories**，只授权 `morpheusdn.github.io`。
4. 回到后台打开 `MorpheusDN/morpheusdn.github.io`，选择 `main` 分支。配置会从仓库自动加载，不需要重新创建配置。

GitHub 登录、双重验证和首次 App 授权需要由账号持有人完成。博客本身仍由 GitHub Pages 托管，无需另外部署服务，也不需要把 GitHub token 写进前端。

## 写文章

1. 点击 **文章 · 默认站点**，新建文章。
2. 填写标题、摘要、发布日期、分类、标签与正文。
3. 创建时确认文件名。建议使用 `my-first-post.md` 这样的英文短横线名称，文件名会成为文章网址的一部分。标题可以使用中文；当前主题默认站点的界面语言仍为英语。
4. 在正文编辑器中排版或插入图片，也可以切换到 Source 查看 Markdown。第一张 Markdown 图片会用于文章列表缩略图；文章顶部的大横幅仍沿用主题原有的生成方式。
5. 新文章默认开启 **草稿**。可以先保存，准备公开时再关闭草稿并保存。
6. 保存会提交到 GitHub。查看仓库的 [Actions](https://github.com/MorpheusDN/morpheusdn.github.io/actions)，等待 **Publish blog** 成功后访问博客。

**文章 · 西班牙语版** 对应 `/es/` 站点。后台自动填写各入口的 `lang`，不需要手动修改。两种语言的文章使用相同文件名时，主题的语言切换可以关联它们；后台不会自动翻译文章。

**最近更新** 可以留空。删除已填写的更新日期不会导致构建失败。**首页推荐** 控制主题原有的推荐标记。

富文本模式适合常规 Markdown。如果文章中使用了自定义 HTML 或复杂嵌入，请用 Source 模式编辑这些部分，并在发布后检查显示效果。

## 修改资料与项目

**站点与个人资料** 可以修改：

- 博客名称、导航栏名称、网站图标路径和搜索关键词。
- 两种语言的显示名称、个人签名与关于页面正文。
- 头像。可以选择已有图片或上传新图片；构建时继续生成适合显示尺寸的 WebP 和社交分享图片。
- 导航菜单的顺序、页面路径和社交链接。导航名称使用已有的多语言选项。

当前网站保留英语和西班牙语两个版本，因此带语言的资料需要分别填写。关于页面正文使用纯文本，不会渲染 Markdown。

**项目展示** 可以新增、删除、排序项目，填写项目地址、两种语言的简介和状态、技术栈，并从列表选择图标。

这些修改均在保存并成功构建后显示到网站。

## 图片管理

- **文章图片** 保存到 `public/covers/`，正文使用 `/covers/文件名` 这样的路径。已有示例图片可以继续使用。
- **头像** 保存到 `src/assets/`，选中的源文件路径记录在站点设置中；这不是公开图片 URL，页面会使用 Astro 构建后的图片地址。
- 新上传图片使用随机文件名，避免同名覆盖已有图片。
- 删除图片前，先确认文章或站点设置已经不再引用它。

## 与本地编辑配合

后台保存后，远程仓库会产生新的提交。下一次在本地修改前，先运行：

```sh
git pull --ff-only
```

如本地已有未提交的修改，先提交或妥善暂存，再拉取远程更新。

## 排查问题

- **找不到仓库**：检查 GitHub App 是否授权给仓库所属账号，以及是否选中了这个仓库。
- **看不到编辑入口**：检查分支是否为 `main`、该分支是否包含 `.pages.yml`，然后刷新后台。
- **保存后博客没有变化**：检查是否仍开启草稿，或 Actions 中的发布是否尚未完成、是否失败。
- **要改颜色、布局或增加语言**：这些仍是主题开发工作；本次后台管理文章、资料和项目数据。

配置入口为仓库根目录的 `.pages.yml`。`settings.content.merge: true` 用于保留表单未管理的现有配置键，例如 `text` 中的翻译覆盖。

官方参考：[快速开始](https://pagescms.org/docs/quick-start/)、[配置文档](https://pagescms.org/docs/configuration/)。
